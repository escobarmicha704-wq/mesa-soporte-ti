# Carpeta docs

| Archivo / carpeta | Para qué sirve |
|---|---|
| `GUIA_PASO_A_PASO.md` | Propuesta de solución, configuración del tablero, hitos, informe y plantillas |
| `TABLERO_DIA_A_DIA.md` | Qué mover y completar en el tablero cada día |
| `backlog.csv` | Las 31 tareas con rol, hito, prioridad, estimación y fecha |
| `crear_issues.sh` | Crea las etiquetas e issues con GitHub CLI (no probado contra GitHub) |
| `plantillas/` | Plantillas a copiar y completar como evidencia de cada hito |
| `traspasos/` | Aquí se guardan los traspasos H1→H2, H2→H3, H3→H4 |
| `evidencias/` | Aquí se guardan las capturas del tablero con fecha |
